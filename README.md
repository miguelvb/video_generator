# AI Video Prototype

## Correct file layout

This archive has been rebuilt so file extensions match their contents:

- `*.py` = Python
- `*.json` = JSON
- `*.ts` / `*.tsx` = TypeScript / TSX
- `*.svg` = SVG
- `*.md` = Markdown
- `*.png` = image assets

## Pipeline

```text
project/script.md
        |
        v
  scene JSON files
        |
        +--> OpenRouter Image API
        |
        +--> TTS adapter
        |
        v
     Remotion
        |
        v
      MP4
```

The exact source voiceover is stored in each scene JSON. The bilingual TTS configuration is stored in `audio/voiceover_manifest.json`.

## Install

```bash
npm install
```

Validate:

```bash
python scripts/validate_project.py
```

Generate placeholder audio for pipeline testing:

```bash
python scripts/orchestrator.py --prepare
```

Generate the real bilingual female voiceover with OpenAI:

```bash
python scripts/orchestrator.py --audio
```

The TTS step generates Spanish narration as `es-ES` and the English quotations as `en-US`, using the same female-sounding voice for continuity. It also writes exact segment timings for Remotion.

Generate images:

```bash
export OPENROUTER_API_KEY="YOUR_KEY"
export OPENAI_API_KEY="YOUR_OPENAI_KEY"
python scripts/orchestrator.py --images
python scripts/orchestrator.py --audio
```

Preview:

```bash
npm run start
```

Render:

```bash
npm run render
```

## Voiceover

The production voiceover is generated by OpenAI `gpt-4o-mini-tts`. The project uses the same female-sounding `shimmer` voice for continuity, with separate instructions for native `es-ES` narration and native `en-US` quotations. The generated audio is split into language segments first, then concatenated per scene. Actual segment durations are written to `audio/generated_voiceover_manifest.json` and `src/generated/audioTimings.ts`, which Remotion uses for quote overlays and scene timing.

The project does not include API keys. Copy `.env.example` to `.env` and add your own keys.

## Important

The generated storyboard/reference images are visual references for the prototype. The next iteration will make Remotion consume the scene JSON generically and animate separate SVG/image assets rather than relying on a single background image per scene.

## Storyboard reference integration

`assets/reference/storyboard.png` is used as the visual reference for both scene generations.
The reference is sent to OpenRouter through `input_references` by `scripts/orchestrator.py`.
The storyboard is guidance only: the generated scene prompt explicitly asks for a single
full-frame scene without the storyboard's chapter/voiceover/SFX layout.

The image-generation model can be overridden with `OPENROUTER_IMAGE_MODEL` in `.env`.
The selected model must support `input_references`.
